# 光伏融资置换 · 智能测算（对外获客版）

纯前端工具：客户填入现有光伏电站贷款信息，自动生成《融资置换与资产盘活综合服务方案》。
**数据完全在客户浏览器内计算，不上传任何服务器**（融资信息属敏感商业数据，纯前端最安全）。

## 文件
- `index.html` — 页面、表单、报告样式
- `app.js` — 计算引擎（表2逻辑）+ 报告渲染（文档1结构）

## 本地预览
```
cd 本目录
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 上线前必做（2 步）
1. 打开 `app.js`，把顶部 `WECHAT.id` 改成你的微信号（默认占位"请替换为你的微信号"）。
2. 需要二维码：把二维码图片命名为 `qr.png` 放到本目录（自动显示，加载失败则回退文字）。
   * 署名已是中性「光伏资产融资服务团队」，无需暴露公司名。

## 公网部署（得到可分享 https 链接，任选其一）
- **Netlify Drop**（最快）：打开 app.netlify.com/drop，把本目录拖进去，秒得全球链接。
- **腾讯云 EdgeOne Pages / 阿里云 OSS+CDN / GitHub Pages**：上传本目录静态文件即可。
- 也可交给 AI 助手用 CloudStudio 等工具一键部署（本机环境需该工具可用）。

## 计算口径
- 月供：等额本息 / 等额本金；年本息、融资利息、服务费(融资额×比例)、评估费、管理费(年电费×年限×比例)、运维费(装机×费率×年限)、多融金额、富余资金、降本。
- **A/B 类自动判断**：年净现金流增加且全周期降本 →「真实降本型」；否则「资金放大型」，文案自适应。
- 新方案参数可在表单「新方案参数」区微调，默认：利率 4%、服务费 5%、管理费 2.5%、运维 1 万/MW/年。
